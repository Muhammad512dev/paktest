# Pak Parcha AI - Universal Notes Hub (Class 9, 10, 11, 12)

A modern, high-speed multi-class web portal to select classes and subjects, set custom download paths, and download complete notes in the background.

---

## Features:
1. **Multi-Class Support**:
   - **Class 9**: 10 Subjects (629 notes)
   - **Class 10**: 10 Subjects (893 notes)
   - **Class 11 (1st Year)**: 9 Subjects (785 notes)
   - **Class 12 (2nd Year)**: 9 Subjects (584 notes)
   - *Total: Over 2,890 note files!*
2. **Selective or Bulk Downloading**:
   - Pick single or multiple classes.
   - Filter specific subjects (Mathematics, Physics, Chemistry, Biology, Computer Science, English, Urdu, Islamiat, Tarjuma Tul Quran, Pakistan Studies).
   - "Select All" / "Clear" one-click toggles.
3. **Custom Download Location**:
   - Set any folder on your hard drive (e.g., `D:\Notes` or `C:\Users\...\Downloads\PakParcha_Class_Notes`).
   - Click "Open" to jump directly to the downloaded files in Windows Explorer.
4. **Organized File Structure**:
   - Automatically organizes into clean subfolders:
     `<Selected_Folder>/<Class_Name>/<Subject_Name>/Unit_XX_Title.pdf`
5. **Background Downloads & Live Dashboard**:
   - Runs in the background so you can work on other tasks.
   - Real-time animated progress bar, speed tracker, active file name, and log terminal.
6. **Direct Google Chrome Launch**:
   - Opens as a native app window inside Google Chrome without launching Microsoft Edge.

---

## How to Launch:
Double-click **`Launch_Notes_Hub.bat`** inside `universal_notes_downloader/`.
